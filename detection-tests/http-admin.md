# ICMP Detection Test - HTTP / Suspicious path to administrator page 

## 1. Objective

The objective of this test is to verify that the SOC lab can detect
HTTP requests to an administrative web page using Suricata and
successfully forward the alert to Wazuh.

This test demonstrates detection of potentially sensitive access to
an administrative web interface.


## 2. Lab Environment

- IDS Server: SOC-IDS-01
- IDS: Suricata
- SIEM: Wazuh
- Source: 192.168.0.4
- Destination: 172.16.0.4 / Nginx server
- Protocol: HTTP
- Port: 80


## 3. Detection Rule

Suricata uses a custom rule in `local.rules` to detect HTTP access to an administrative page.
```
alert http any any -> $HOME_NET any (msg:"SOC LAB - Suspicious HTTP Admin Path"; http.uri; content:"/admin"; sid:1000002; rev:1;)
```

### Rule Explanation

- **Protocol:** HTTP/TCP
- **Destination:** HTTP server
- **Port:** 80
- **Detection:** Administrative page access
- **SID:** 1000002
- **Message:** "SOC LAB - Suspicious HTTP Admin Path"

The rule is designed to identify requests to an administrative
web resource that may require additional monitoring or investigation.

## 6. Suricata to Wazuh Integration

The Suricata alert is written to:

```text
/var/log/suricata/eve.json
```

The custom Python filtering service monitors the Suricata event log
and filters events where:

```text
event_type = alert
```

The filtered alert is written to:

```text
/var/log/suricata/wazuh-alerts.json
```


## 7. Wazuh Agent

The Wazuh Agent on `SOC-IDS-01` monitors the filtered Suricata
alert file:

```xml
<localfile>
  <log_format>json</log_format>
  <location>/var/log/suricata/wazuh-alerts.json</location>
</localfile>
```

The Wazuh Agent forwards the event to the Wazuh Manager over
TCP port 1514.


## 8. Wazuh Dashboard

The Suricata HTTP administrative access alert was successfully
received by Wazuh and displayed in the Wazuh Dashboard.

## 9. Result

**PASS**

The ICMP detection was successfully tested end-to-end.

The ICMP traffic was detected by Suricata, filtered by the custom
Python service, collected by the Wazuh Agent, processed by the
Wazuh Manager, and displayed in the Wazuh Dashboard.
