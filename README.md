# SOC Lab – Wazuh + Suricata

A hands-on Security Operations Centre (SOC) lab built in Azure to demonstrate security monitoring, intrusion detection, SIEM integration, custom detection rules and incident investigation.

## Project Overview

The goal of this project is to build a small SOC environment where security events can be generated, detected, collected, analysed and displayed through a central SIEM platform.

The environment includes:

- Wazuh SIEM
- Suricata IDS
- Ubuntu Linux
- Azure Virtual Machines
- Custom Wazuh detection rules
- Custom Suricata detection rules_py
- Security event filtering_py
- SSH authentication monitoring
- ICMP detection
- Security event investigation
